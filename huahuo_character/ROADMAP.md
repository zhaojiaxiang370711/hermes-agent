# 角色 Agent 后续阶段

第一阶段已完成框架基础；第二阶段已实现常驻 Director 和主工程语音接入，真实文本双角色语音及合成 WAV 经真实 ASR 的部署检查已通过。验证输入与边界见 [README](README.md)。继续沿独立扩展开发，升级上游时保留固定基线与契约检查，避免将角色业务改入 Hermes 核心循环。

| 阶段 | 当前工作与状态 | 仍需完成的验收 |
| --- | --- | --- |
| 1：框架基础 | 已完成角色身份、稳定 session、接话预算、严格动作消息与可选消费端 | 基础协议和现有动作优先级自动检查已通过；不代表真人资产验收 |
| 2：当前游戏与语音 | 常驻 HTTP Director、进程实例 scope、现有 ASR/CosyVoice/WS/Godot 接入、逐句动作关联已实现；文本双角色语音与合成 WAV 真实 ASR 部署检查已通过 | 真人无线麦克风插话、回声、断连/切角色/重启、双摄大屏现场回归待验收；合成 WAV 该轮仅验证派蒙回复，不覆盖多角色接话或动作 |
| 3：独立关系与多角色 | 当前仅 transcript；普通 profile memory 和外部 memory provider 禁用 | 可信用户身份、关系记忆分区、用户删除、空闲状态回收、跨场景策略和主动接话预算；确认不同用户无记忆串用 |
| 4：动画与声音同步 | 台词的 action_request_id 与严格动作事件关联；对应首 PCM 输出前发动作；派蒙动作已接入，两个角色共享音色 | Godot 实际播放时间 ACK、动画完成/取消/失败回执、每角色音色和能力协商；实际资产同步、表情与注视验收 |
| 5：地面与空间行为 | 可莉当前动作白名单为空；导航和接触行为未接入 Agent | 只开放目标意图，由 Godot 执行路径、碰撞、IK和物理约束；固定房间真人验证 |

动画、逐帧骨骼、物理与导航保留在引擎内，不为每帧调用 LLM。未来开放工具以类型化、可撤销的角色能力为单位，先增加实际消费端和验收，再扩展抽象。

当前 Hermes 仍等待 run 完整结束，再把整个有界接话链统一返回；没有接入 Hermes SSE 模型增量流。之后每句 TTS 流式输出。后续可研究逐角色更早交付、SSE 重连与幂等恢复，但需要继续保留完整 JSON 验证、旧回合拒绝和动作授权边界。

真实文本部署结果不能替代真人语音或双摄验收。首 PCM 输出不是扬声器播放 ACK，两个角色共享音色不代表已完成声音区分。后续阶段是开发路线，不是已交付能力或自动定期任务。
